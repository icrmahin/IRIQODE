# Security Policy

IRIQODE is a Visual Studio Code theme extension and currently contains no runtime service or network-facing backend.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner through the contact information on the GitHub profile.

Include the affected version, impact, reproduction steps, and any relevant logs. Do not include secrets or personal data.
