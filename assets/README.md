# Assets

This directory is reserved for IRIQODE-owned project artwork and extension assets.

## Current state

No final extension icon, file icon set, or screenshot assets are included yet.

## Asset requirements

- Record the source, author, license, and attribution requirements for every third-party asset.
- Keep copied or adapted assets inside this repository.
- Do not edit or commit files in the Nacre repository from IRIQODE work.
- Do not present placeholder artwork as final production iconography.

The final IRIQODE extension icon and file icon theme will be designed and reviewed separately.
